# 🚀 Week 1 – Frontend Projects

A collection of Week 1 frontend assignments covering HTML, CSS, and React fundamentals — responsive layouts, reusable components, and dynamic rendering.

## 📂 Projects

| # | Project | Tech | Folder |
|---|---------|------|--------|
| 1 | React Blog UI (Mini Project) | React, JSON, CSS | `/react-blog-ui` |
| 2 | Personal Portfolio Website | HTML, CSS | `/portfolio` |
| 3 | React Components Practice | React (props & state) | `/react-components-practice` |

---

## 1️⃣ React Blog UI

A small React-based blog layout that displays post cards loaded from a JSON file.

**Features**
- Post cards rendered dynamically from `posts.json`
- 🔍 Search posts by title
- 🏷️ Filter posts by category
- Fully responsive layout

**Run locally**
```bash
cd react-blog-ui
npm install
npm run dev
```

---

## 2️⃣ Personal Portfolio Website

A responsive personal portfolio built with plain HTML and CSS.

**Sections**
- **About** – short introduction
- **Education** – academic background
- **Projects** – featured work
- **Contact** – ways to reach me

**Run locally**
Open `portfolio/index.html` in your browser.

---

## 3️⃣ React Components Practice

Five reusable React components with dynamic rendering using props and state.

| Component | Purpose |
|-----------|---------|
| `Header` | Site title and navigation |
| `Footer` | Page footer with credits |
| `Card` | Reusable content card driven by props |
| `Button` | Configurable button (label, onClick, style) |
| `Form` | Controlled form managed with state |

**Run locally**
```bash
cd react-components-practice
npm install
npm run dev
```
